# Future Salary Predictor

A mobile-first React quiz funnel prototype for Grade 12 students exploring engineering degree choices.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Optional integrations

- Add `VITE_LEAD_WEBHOOK_URL` in `.env` to post lead payloads to your CRM/webhook.
- Use `?debug=1` in the URL to reveal score breakdown in the result card.
